# 第二轮兼容修复与回归

测试仍使用手机 Download 下的 94 个原文件（45 HWP、49 HWPX）的私有缓存副本，原件未修改。每个文件冷启动同一个 Activity 并启用 Debug verify，采集进程对应的 LOADED / SMOKE_OK / READER_ERROR。

本轮补齐：HWP 页眉页脚、母版文字、脚注/尾注/隐藏说明及字段元数据识别；常用公式原生 MathML；SVG MIME 别名；OLE Bitmap 与 WMF/EMF 静态预览；旧版图表 VtArchive 原始行列数据；长表格与嵌套单元格跨页；含图片长段落拆页。HWPX 的无效/继承边距及有符号位移按语义处理，避免超大空白。说明和字段提示可展开，搜索会展开命中的说明。

XML 核对现在为每个原始 t 节点分配编号，跨页后按编号合并片段。去除空白后，正文片段与原始节点逐一比较，以检查遗漏、重复和改变；重复页眉页脚单独处理。HWP 没有同样的独立 XML 基准，检查解析模型、实际 DOM、搜索前后文本和图片。加载通过不等于逐像素还原。

旧版图表样本的 Contents 只有私有图表数据，没有静态预览。当前读取出完整 6 行 5 列，按原始网格显示；未猜测图表类型、系列方向或原图样式。视频样本只链接外部 Windows AVI 文件，文档包仅包含封面，不能从该文档恢复视频。分发保护 HWP 仍拒绝打开。

公式、艺术字曲线、复杂分组和矢量绘图指令仍有覆盖范围与字体差异；本轮针对语料中的实际公式、图像与表格验证，不代表支持所有 HWP/HWPX 规范特性。超大文档只挂载相邻页，验证了首末页与全文搜索，未逐页人工查看 16,384 页。

`results.json` 和 `results.csv` 保存逐文件结果，`summary.json` 保存统计，`build-under-test.json` 记录最终 APK 与引擎哈希。`host-*-results.json` 为解析/公式/图表单元测试；`screenshots/` 为实机抽样。
