# 分发保护 HWP 只读支持

按 Hancom 公开的分发文档 revision 1.2 规范读取 ViewText/Section。正文只在内存中解码，再进入现有的统一 Activity 和渲染模型，不改写原文件，不输出解码后的 HWP，也不运行文档脚本。

对每一节的权限做交集：任意节禁止复制或打印，整个阅读页面即禁止该项功能。禁止复制时关闭正文选择、复制/剪切/拖拽事件和原生长按；禁止打印时禁用原生打印按钮，并在 JS 与原生打印入口检查权限。跨文档切换会重置权限，异步打印回调校验原文档会话。

真实样本 distribution.hwp 使用 ViewText 正文，BodyText 中另有内容。测试明确要求读取 ViewText，不允许在缺失或损坏时回退 BodyText。样本显示为 3 页、2,326 字符，权限为只读、禁止复制、允许打印，搜索和跳页通过。原文件保持不变。

`host-distribution-results.json` 使用 Node AES 独立构造四种权限组合、压缩/未压缩流和多节文档，验证正文、权限合并、输入字节不变、截断和缺失 ViewText 的拒绝路径；密码加密和 DRM 拒绝测试仍保留。`device-fixtures.json` 保存四种权限组合的实机自检与原生打印按钮检查。`results.json` 为同一批 Download 文件的最终全量回归。

该功能是分发文档阅读支持，密码、DRM 和证书加密仍不支持。一般格式的复杂图表样式与外链视频限制见上轮报告。

본 제품은 한글과컴퓨터의 글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.
